# Что это за сервис

Хаб агентов: место, где вы описываете ИИ-агентов, даёте им инструменты и
память и запускаете их поодиночке или группами на реальной работе в рабочем
пространстве.

## Как вложены объекты

Почти всё обучение сводится к тому, чтобы понять, что в чём лежит.

```
workspace                  an isolated folder + its own agents, settings and memory
 ├── project               one codebase or effort inside the workspace
 │    └── task             a unit of work, with subtasks and dependencies
 ├── agent                 a definition: prompt + tools + model + memory
 ├── flow                  a graph of agents, run as one pipeline
 │    └── loop             a flow re-run until a judge says it is good enough
 ├── team                  a roster of agents working over a shared board
 └── view                  a chart, graph or 3D scene an agent built
```

По-русски это читается так. Рабочее пространство (workspace): изолированная
папка со своими агентами, настройками и памятью. В нём лежат проекты
(project: одна кодовая база или одна работа), а в проектах задачи (task:
единица работы с подзадачами и зависимостями). Агент (agent): описание из
промпта, инструментов, модели и памяти. Поток агентов (flow): граф агентов,
который запускается как один конвейер, а цикл (loop) перезапускает поток,
пока судья не решит, что результат достаточно хорош. Команда (team): состав
агентов, работающих над общей доской. Представление (view): диаграмма, граф
или 3D-сцена, которую построил агент.

Запуск любого из этих объектов создаёт одни и те же три записи, и именно
благодаря им за системой вообще можно наблюдать:

- **запуск**: одно обращение к агенту. Это атом, из запусков состоит всё.
- **сессия**: разговор, то есть запуски, которые относятся друг к другу.
- **инстанс**: живая копия агента со своим состоянием и историей.

## Два вида агентов

**Системные агенты** поставляются вместе с продуктом. Они есть в каждом
рабочем пространстве, удалить их из пространства нельзя, а их инструменты и
описания всегда соответствуют тому, что поставляет продукт. Благодаря им
сервис работает сразу после установки. См. [system-agents](system-agents.md).

**Пользовательские агенты** принадлежат вам. Вы их создаёте, добавляете в
нужные рабочие пространства, и ничто из поставки продукта их не изменит.

## Где на самом деле идёт работа

- **Чат** служит входной дверью: говорите с любым агентом напрямую, без
  настройки.
- **Задачи** нужны для отслеживаемой работы: её назначают, разбивают на этапы
  и могут продолжить с того места, где она остановилась.
- **Потоки агентов, циклы и команды** нужны для работы, которой
  мало одного агента или одного прохода.

## Меню

Боковое меню повторяет то же дерево в пяти группах: **Разговор** (Чат),
**Работа** (проекты, задачи, план, артефакты, потоки агентов, циклы, команды,
оркестратор, развёртывания, рабочие пространства), **Агенты и библиотека**
(агенты, модели, навыки, память, маркетплейс, набор инструментов, инстансы),
**Интеграции** (коннекторы) и **Записи и администрирование** (сессии, запуски,
группы запусков, веб-запросы, guardrails, контейнеры, статус, настройки,
документация).

У меню два режима. **Простое меню** оставляет четырнадцать страниц,
нужных новичку, в том числе рабочие пространства, плюс Настройки и
Документацию. Оно включено по умолчанию. **Полное меню** показывает все
страницы. Переключатель внизу меню меняет режим, и браузер запоминает выбор.
Ни в одном режиме страницы не исчезают, а простое меню не меняет вида:
страница вне его подсвечивает строку, к которой относится (Развёртывания,
открытые со страницы Плана, подсвечивают План, Циклы и Команды подсвечивают
Потоки агентов, Коннекторы, Сессии и остальные записи подсвечивают Настройки).

## Две вещи, которые стоит знать с самого начала

**Деньги настоящие.** Каждый запуск тратит токены. Команда стоит число участников,
умноженное на число раундов; цикл повторяет целый поток. Инструменты, которые
это запускают, отказываются работать, пока вы не дадите согласие, и в отказе
указана оценка стоимости. На странице каждого запуска
показано, сколько он стоил.

**Возможности ограничиваются принудительно.** Агент, который может читать ваши
личные данные, получать текст извне *и* отправлять данные наружу, становится
готовым инструментом для утечки данных. Продукт не предупреждает о таком
сочетании, а просто его запрещает. См.
[tools-and-capabilities](tools-and-capabilities.md).
