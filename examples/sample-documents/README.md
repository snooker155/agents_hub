# Sample Documents

Throwaway input files for trying features that need a document to chew on. None
of them is read by the code; they exist so a walkthrough has something concrete
to upload.

| File | Use it for |
|---|---|
| `rag_paper_sample.txt` | RAG ingestion: index it, then ask an agent a question only the file can answer |
| `sample_memory_document.txt` | Memory extraction: an internal-platform reference doc with facts worth remembering across sessions |
| `sample_dnd_extraction.txt` | Structured extraction: session notes with items, NPCs and open threads to pull out into fields |

Upload one to a workspace (Workspaces → Files), or point an ingestion run at it
by path. Nothing here is required to run the service.
