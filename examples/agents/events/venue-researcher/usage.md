Use this agent when an event needs a structured venue shortlist.

Good fits:
- "Compare three London venues for a 200-person conference"
- "Build a venue ranking with cost-per-head and AV notes"

Poor fits:
- Final booking — the agent recommends, it doesn't transact
- Non-event venue searches

How to invoke:
- State the event details: attendee count, location, dates, must-have amenities
- The agent saves a ranked report under `venues/<event_slug>.md` with pros, cons, and a clear recommendation
