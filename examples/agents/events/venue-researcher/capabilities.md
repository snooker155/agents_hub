- Plan a venue evaluation approach with the `plan` tool
- Reason about capacity, location, AV, accessibility, and catering with `think`
- Read and write files in the workspace
- Run cost arithmetic via the calculator
- Save structured comparison reports to `venues/<event_slug>.md`

What this agent does NOT do:
- Recommend a venue without an estimated cost
- Skip flagging venues that lack AV or catering
- Run shell commands or execute code
