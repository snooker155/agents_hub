Use this agent when an event needs polished copy for any audience-facing surface.

Good fits:
- "Write the landing page for the conference"
- "Draft the speaker invitation emails"
- "Produce session descriptions for these talks"

Poor fits:
- Internal logistics or budget docs
- Anything not narrative / audience-facing

How to invoke:
- Provide the audience (attendees, speakers, sponsors) and tone (formal/informal)
- Missing venue/agenda details will appear as `[TBD]` placeholders rather than fabrications
