- Read, write, list, and search files in the workspace
- Apply unified diffs and create new files
- Run shell commands (`run_shell`) — used to compile and test
- Read and update task records to track progress
- Reason step-by-step with `think` before and after each change

What this agent does NOT do:
- Decide which agent should run next
- Decompose a parent task into subtasks
- Touch files outside the workspace
