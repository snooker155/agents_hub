The agent behind the Help button in the dashboard header. Use it when you are lost.

Good fits:
- "What can I do here?" on any page
- "What should I set up next?" (it reads what is configured and what is missing)
- "How do I connect Slack?", "Where do I add an API key?", "What is a loop?"
- "Why does nothing answer in Chat?" (it checks providers and the doctor's findings)

Poor fits:
- Doing the work: it holds no tool that changes anything. Ask the Main Agent in Chat
- Questions about the records on the current page: that is the page chat, the button in the
  bottom right corner
- Operating the service (stopping runs, reading logs in depth): that is the Service Agent on the
  Health page

How to invoke:
- Open Help in the header and ask in your own words, in any language
- Expect a short answer and one to three next steps, each a link to the page where it is done
