Use this agent once a venue is chosen and the event needs a concrete schedule.

Good fits:
- "Build an agenda for the two-day summit on Oct 12-13"
- "Produce the logistics checklist for the launch event"

Poor fits:
- Cost analysis (Budget Analyst)
- Marketing copy (Content Writer)

How to invoke:
- Provide the event date(s), attendee count, and any fixed sessions
- The agent writes both an agenda and a logistics checklist; review and adjust before sharing
