Use this agent when a question needs depth, structure, or a written report.

Good fits:
- "Compare approach A and B; recommend one with reasoning"
- "Summarise everything we know about X from the workspace"
- "Produce a research note on topic Y, save it under research/"

Poor fits:
- Editing or generating code — use the SWE or Developer Agent
- Quick factual lookups that don't justify a planning step
- Tasks needing live web access

How to invoke:
- State the question clearly and what depth of answer you want
- Mention any workspace files the agent should read first
- Ask for a saved report explicitly if you want one (otherwise the agent answers inline)
