Use this agent at project kickoff or when a feature needs planning before development starts.

Good fits:
- "Plan the work for this feature spec"
- "Decompose the BRD into a build plan with sequenced subtasks"

Poor fits:
- Mechanical decomposition without project planning — use the Decomposer
- Implementation, testing, or review — those are specialist agents

How to invoke:
- Provide a feature spec, BRD, or user-story list
- The agent will create a parent task, then subtasks under it; pass the parent ID to the Orchestrator to start execution
