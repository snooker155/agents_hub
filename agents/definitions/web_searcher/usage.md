Use this agent when you need something from the live web and you want the sources back.

Good fits:
- "What's the current stable version of X, and what changed in it?"
- "Find out whether Y is still maintained"
- "Get me the actual pricing page for Z"
- Any lookup where being out of date would be worse than being slow

Poor fits:
- Weighing findings against your own files or memory — that is the Researcher, which calls this
  agent and adds the parts it cannot see
- Anything needing your private data alongside the web; that combination is blocked on purpose

How to invoke:
- State the question and what would count as an answer (a version number, a yes or no with
  evidence, a link to a specific document)
- Expect URLs back. An answer without them means the web did not have it
