- List and inspect projects across a workspace, with their type, status, repo link and task count
- Create projects, including their folder inside the workspace
- Modify projects: name, description, status, type, tags, and the repo / frontend / backend configuration
- Archive projects (the reversible alternative to deletion)
- Delete project records and their structure graphs (blocked while tasks are still attached; files on disk are kept)
- Read the tasks attached to a project

What this agent does NOT do:
- Clone, push, or sync a git repo, or import issues — those live on the Projects page
- Create or delete workspaces
- Write code or edit workspace files (use the SWE Agent)
- Create or modify tasks in bulk (use the Planner)
