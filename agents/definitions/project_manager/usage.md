Use this agent to maintain the project registry.

Good fits:
- "Create a research project called Pricing Study in this workspace"
- "Point the hrms project at github.com/acme/hrms, branch develop"
- "Archive every project that has no open tasks"
- "Which projects are in this workspace and how much work is attached to each?"
- "Mark the migration project completed and tag it legacy"

Poor fits:
- Cloning a repo or syncing issues — that is the Projects page
- Creating a workspace — projects live inside one that already exists
- Doing the project's actual work — that is the SWE Agent's job

How to invoke:
- Name the project (or describe it) and the change you want
- The agent reports the project_id and the folder the project owns inside the workspace
