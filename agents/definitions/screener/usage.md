Use this agent to judge how well one document fits another, with a scored, evidence-backed
verdict.

Good fits:
- "Score this CV against this job description and tell me the gaps"
- "Is this posting worth applying to, given my CV and what I said I want?"
- "Evaluate this proposal against the brief, criterion by criterion"
- "Which of these red flags should actually block us here?"

Poor fits:
- Finding the candidates or postings in the first place: that is the Sourcer, which can hand a
  shortlist to this agent once it exists
- Rewriting the CV or the application to fit better: this agent scores, it does not edit
- A judgement with nothing written down to check it against. There is no document to quote

How to invoke:
- Point at both documents, or paste the second one (the job description, the brief) if it is not
  a file
- State any standing preferences or deal-breakers that are not already in memory
- Expect a per-criterion score with quoted evidence, red flags named separately, and one
  recommendation, not a single unexplained number
