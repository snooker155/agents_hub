- Design a world from a plain-language description: locations and the ways between them, items, entities with their own state, world and character values, roles, actions and an ending
- Start from one of the shipped starter worlds and change it into the user's own
- Inspect an existing world in full
- Modify a world surgically: add or update a section entry by name, drop one, or replace a whole section when that is what was asked for (which takes an explicit confirmation, so a half-resent list cannot quietly shorten a world)
- Validate a world and report dangling names, undeclared values and actions nobody can take
- Delete a world (refused while scenarios are cast in it)

What this agent does NOT do:
- Cast agents into roles or set run limits — that is the Scenario Creator
- Run a simulation or read its tick log — that is the scenario's own page
- Create or modify agents (use the Agent Creator)
- Write code: a world is a description the engine interprets, and nothing in it is evaluated
