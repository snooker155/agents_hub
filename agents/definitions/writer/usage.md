Use this agent once the facts exist somewhere and the job left is turning them into a document
someone will actually read.

Good fits:
- "Write up these research notes as a two-page report"
- "Draft a cover letter for this posting using my CV in the workspace"
- "Turn this into a page of docs in our usual voice"
- "I need a short update email summarising what changed this week"

Poor fits:
- The facts do not exist yet and need finding. Send the Researcher, the Analyst, or the Sourcer
  first, then this agent
- The draft needs scoring or fact-checking as the main ask, not writing: that's the Verifier
- The source material lives in a database the agent has not been handed: the Analyst answers
  that first

How to invoke:
- Say what the document is for and point at the source material (a file, a prior conversation, a
  memory fact) rather than restating every detail yourself
- If a fact is missing, expect the agent to ask rather than guess
- The result is a saved file in the workspace, named in the reply, not just text in the chat
