- Design agent teams from a plain-language brief, using only registered agents
- Create teams (validated before saving: registered agents, unique member names, a leader on the roster, ceilings inside the caps)
- Inspect an existing team's mode, charter, roster and run limits
- Modify teams: rewrite the charter, add or drop members, switch mode, retune the round and cost ceilings
- Delete teams (blocked while one of their runs is live)
- run_team_tool: Start a team run against one goal, once the user has approved the cost (refuses until then)
- get_team_run_tool: Report how a team run is going, or its final answer
- stop_team_run_tool: End a team run that is still going

What this agent does NOT do:
- Create or modify agents (use the Agent Creator)
- Create flows, loops or scenarios (use the Flow Creator, Loop Creator, Scenario Creator)
